.. _pro_alerts_panel:

############
Alerts Panel
############

The alerts panel is located on the left side of the application window and consists of two sections:

.. _pro_alerts_list_panel:

Alerts List
===========

Displays the list of alerts defined by the user.
Selecting an alert highlights it and shows its details in the :ref:`pro_alert_info_panel`.

.. _pro_alert_info_panel:

Alert Info
==========

Displays the configuration of the alert currently selected in the Alerts List.
