#############
Shortcuts Bar
#############

The shortcuts bar provides quick access to the most commonly used actions in *Fast DDS Monitor Pro*.
The full description of each action is available in the :ref:`pro_edit_menu` section of the
:ref:`pro_application_menu`.

The icons available in the shortcuts bar are:

* |dashboard_layout_1| |dashboard_layout_2| |dashboard_layout_3| — Change the main dashboard layout.
* |historical_chart| — Display historical data.
* |dynamic_chart| — Display real-time data.
* |refresh| — Refresh Fast DDS Monitor.
* |clear_log| — Clear the log.
* |clear_issues| — Clear the issues panel.
* |create_alert| — Open the create alerts panel.

The bar can be hidden or revealed from **View → Hide/Show Shortcuts Toolbar**.
Individual buttons can be toggled from **View → Customize Shortcuts Toolbar**.
